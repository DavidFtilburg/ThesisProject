# ThesisProject

The notebooks in this repository contain the necessary code to run all experiments from my thesis.

TFA_TopoMaps_Notebook applies wavelet transform on EEG data from Aurnhammer et al. (2021) and plots the topo maps
MVPA_on_TF_EEG inputs wavelet transformed EEG data into a MVPA pipeline
FrequencySignalSimulator synthetizes frequency signals to point out the effect of temporal leakage
